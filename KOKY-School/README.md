# KOKY School - منصة تعليم اللغة الإنجليزية

منصة تعليمية متكاملة لتعلم اللغة الإنجليزية للمستخدمين الناطقين بالعربية، مع واجهة جميلة وعصرية، وتجربة تعليمية ممتعة وتفاعلية.

## 🌟 الميزات الرئيسية

### 🎯 تعليم شامل للغة الإنجليزية
- **تحسين النطق (Pronunciation)**: تدريبات صوتية تفاعلية مع التعرف على الكلام
- **تحسين مهارات القراءة والكتابة**: تمارين ممتعة وقصص تعليمية
- **فهم المعاني والمفردات**: توسيع المفردات مع تصنيف الكلمات حسب المستوى
- **قواعد اللغة**: دروس تفاعلية مع أمثلة عملية
- **تمارين تفاعلية**: ألعاب تعليمية ممتعة لجميع المستويات

### 📊 نظام مستويات وتصنيف المستخدمين
- **تقسيم المتعلمين**: مبتدئ، متوسط، متقدم
- **تتبع التقدم**: إحصائيات مفصلة وتحليلات أداء
- **الإنجازات والشارات**: نظام مكافآت وتحديات لتحفيز التعلم
- **الاستمرارية**: تتبع السلاسل اليومية وتحفيز الدراسة المنتظمة

### 🎨 تجربة مستخدم ممتعة وجذابة
- **واجهة جميلة**: تصميم عصري مع دعم الوضع الفاتح والداكن
- **رسوم متحركة**: تأثيرات بصرية ممتعة وسلسة
- **أصوات تعليمية**: محتوى صوتي تفاعلي وتحفيزي
- **دعم عربي كامل**: واجهة بالكامل باللغة العربية

### 🔧 ميزات تكميلية
- **قوائم كلمات يومية**: توسيع المفردات بشكل يومي
- **اختبارات قصيرة**: تقييم فوري بعد كل درس
- **ملخصات ذكية**: مراجعة سريعة للمحتوى المتعلم
- **ترجمة فورية**: دعم ترجمة فورية للنصوص
- **نصائح تحسين**: اقتراحات تلقائية لتحسين النطق والكتابة

## 🛠️ التقنيات المستخدمة

### Frontendٍ
- **React 18** - مكتبة واجهة المستخدم
- **Next.js 14** - إطار عمل React مع تطبيقات الصفحة
- **TypeScript** - كتابة الشيفرة النصية
- **Tailwind CSS** - تنسيق CSS حديث
- **Framer Motion** - رسوم متحركة وتأثيرات
- **Zustand** - إدارة الحالة
- **React Hook Form** - إدارة النماذج
- **React Hot Toast** - إشعارات المستخدم
- **React Confetti** - تأثيرات احتفالية
- **React Speech Kit** - التعرف على الكلام
- **React Chart.js 2** - رسوم بيانية وتصورات بيانات

### مكتبات دعم
- **Lucide React** - أيقونات جميلة
- **React Icons** - مكتبة أيقونات متنوعة
- **Class Variance Authority** - تنوعات المكونات
- **Date-fns** - معالجة التواريخ والأوقات

## 🚀 بدء الاستخدام

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/your-username/koky-school.git
cd koky-school
```

2. تثبيت التبعيات:
```bash
npm install
```

3. تشغيل الخادم في وضع التطوير:
```bash
npm run dev
```

4. افتح المتصفح وانتقل إلى:
```
http://localhost:3000
```

### بناء المشروع للإنتاج
```bash
npm run build
npm start
```

## 🔧 الميزات المطورة

### 1. نظام المستخدمين والمستويات
- **تسجيل الدخول**: واجهة تسجيل دخول بسيطة
- **المستويات**: مبتدئ، متوسط، متقدم
- **التقدم**: تتبع دقيق للتقدم في كل مهارة
- **الخبرة**: نظام نقاط XP لتحفيز المستخدمين

### 2. تدريب النطق
- **التعرف على الكلام**: استخدام Web Speech API
- **تقييم النطق**: مقارنة مع النطق الصحيح
- **تصحيح فوري**: ملاحظات فورية على الأداء
- **تمارين متنوعة**: كلمات وعبارات مختلفة المستويات

### 3. تمارين القراءة
- **قصص قصيرة**: محتوى قراءة متنوع
- **أسئلة فهم**: أسئلة متعددة الخيارات
- **توقيت**: إدارة الوقت للتدريب على الامتحانات
- **تقييم فوري**: نتائج فورية مع شرح الإجابات

### 4. المفردات والقواعد
- **تصنيف الكلمات**: حسب المستوى والفئة
- **مراجعة متباعدة**: تعزيز الذاكرة طويلة المدى
- **تمارين تفاعلية**: ألعاب ومطابقة الكلمات
- **قواعد نحوية**: شروحات مبسطة مع أمثلة

### 5. تتبع التقدم
- **إحصائيات مفصلة**: رسوم بيانية وتحليلات
- **الإنجازات**: شارات ومكافآت
- **التقارير**: تقارير أسبوعية وشهرية
- **التوقعات**: توقعات للأداء المستقبلي

### 6. الترجمة الفورية
- **ترجمة فورية**: ترجمة نصوص فورية
- **نطق**: قراءة النصوص المترجمة
- **نسخ**: نسخ النصوص إلى الحافظة
- **تاريخ**: حفظ سجل الترجمات
